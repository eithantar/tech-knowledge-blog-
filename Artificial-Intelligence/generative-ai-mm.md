# Generative AI (Gen-AI)

> ဖတ်ရန်: [English](generative-ai-en.md) | **မြန်မာ**

## ၁။ Generative AI (Gen-AI) ဆိုတာဘာလဲ?

- **Subset of Deep Learning:** Generative AI ဆိုတာ Deep Learning ရဲ့ အစိတ်အပိုင်းခွဲတစ်ခု ဖြစ်ပါတယ်။ ဆိုလိုတာက သူဟာ Artificial Intelligence (AI) ရဲ့ အဆင့်မြင့်ဆုံး နည်းပညာတွေပေါ်မှာ အခြေခံထားတာပါ။
- **Generate new data:** သူ့ရဲ့ ထူးခြားချက်က အချက်အလက်အသစ်တွေကို ဖန်တီးပေးနိုင်တာ ဖြစ်ပါတယ်။
- **Similar to the data it was trained on:** သူဟာ အချက်အလက်အသစ်တွေကို ဖန်တီးတဲ့နေရာမှာ အလွတ်သဘော ဖန်တီးတာမဟုတ်ဘဲ သူ Trained ထားတဲ့ အချက်အလက်တွေနဲ့ ဆင်တူတဲ့ ပုံစံမျိုးကို ထုတ်ပေးတာ ဖြစ်ပါတယ်။

### Gen-AI က ဘာတွေကို ဖန်တီးပေးနိုင်သလဲ?

Generative AI ကို အသုံးပြုပြီး အောက်ပါ Output တွေကို ထုတ်လုပ်နိုင်ပါတယ် -

- **Text (စာသားများ):** ဥပမာ - Email ရေးခြင်း၊ ပုံပြင်ပြောခြင်း၊ မေးခွန်းများကို ဖြေကြားခြင်း (ChatGPT လိုမျိုး)။
- **Image (ရုပ်ပုံများ):** ဥပမာ - စာသားနဲ့ အမိန့်ပေးရုံနဲ့ အသစ်စက်စက် ပန်းချီကား ဒါမှမဟုတ် ဓာတ်ပုံများ ဖန်တီးခြင်း။
- **Audio (အသံ):** ဥပမာ - သီချင်းအသစ်များ ဖန်တီးခြင်း သို့မဟုတ် လူ့အသံအတိုင်း စာဖတ်ပေးခြင်း။
- **Code (ပရိုဂရမ် ကုဒ်များ):** ဥပမာ - Developer တွေအတွက် Programming code တွေကို ရေးပေးခြင်း။
- **Video (ဗီဒီယို):** ဥပမာ - စာသားအချက်အလက်ပေါ် မူတည်ပြီး ဗီဒီယိုအတိုလေးများ ဖန်တီးပေးခြင်း။

### ရိုးရိုး AI နဲ့ Gen-AI ဘာကွာသလဲ? (နားလည်လွယ်အောင် ဥပမာပေးရရင်)

- **Traditional AI :** ဓာတ်ပုံတစ်ပုံကို ကြည့်ပြီး "ဒါဟာ ကြောင်လား၊ ခွေးလား" ဆိုတာကို ခွဲခြား (Classify) တာ ဒါမှမဟုတ် ခန့်မှန်းတာမျိုးပဲ လုပ်ပါတယ်။
- **Generative AI:** "ကြောင်ပုံလေးတစ်ပုံ ဆွဲပေးပါ" လို့ ပြောလိုက်ရင် အရင်က လုံးဝမရှိသေးတဲ့ ကြောင်ပုံအသစ်တစ်ခုကို ဖန်တီး (Create) ပေးလိုက်တာမျိုး ဖြစ်ပါတယ်။

## ၂။ Foundation Model (FM) ဆိုတာဘာလဲ?

Foundation Model ဆိုတာ AI ရဲ့ "အုတ်မြစ်" ဒါမှမဟုတ် "ဗဟုသုတအခြေခံ" လို့ နားလည်ထားလို့ ရပါတယ်။

- **Reliance on Foundation Model:** အချက်အလက်သစ်တွေကို Generate ဖို့အတွက် ကျွန်တော်တို့ဟာ Foundation Model တစ်ခုခုပေါ်မှာ မဖြစ်မနေ အခြေခံရပါတယ်။ သူ မရှိဘဲ Gen-AI အလုပ်မလုပ်နိုင်ပါဘူး။
- **Trained on wide variety of data:** ဒီ model တွေကို အင်တာနက်ပေါ်မှာရှိတဲ့ စာအုပ်တွေ၊ ဆောင်းပါးတွေ၊ ရုပ်ပုံတွေနဲ့ code တွေ အစရှိတဲ့ အချက်အလက် အမြောက်အမြား (Huge amount of data) ကို အသုံးပြုပြီး လေ့ကျင့်ပေးထားတာ ဖြစ်ပါတယ်။ ဒါကြောင့် သူတို့က အကြောင်းအရာ တော်တော်များများကို သိနေတာပါ။
- **Costly to train:** ဒီလို model ကြီးတစ်ခု ဖြစ်လာဖို့အတွက် လိုအပ်တဲ့ Computing Power က အရမ်းကြီးမားတာကြောင့် Training Cost ဟာ ဒေါ်လာ သန်းချီပြီး ကုန်ကျပါတယ်။

### ဥပမာများနှင့် ကုမ္ပဏီများ

- **Example (GPT-4o):** ကျွန်တော်တို့ သုံးနေတဲ့ ChatGPT ရဲ့ နောက်ကွယ်က Foundation Model ဟာ GPT-4o ဖြစ်ပါတယ်။
- **Major Providers:** အခုအချိန်မှာ ကမ္ဘာကျော် ကုမ္ပဏီကြီးတွေက သူတို့ရဲ့ Foundation Model တွေကို ထုတ်လုပ်ထားကြပါတယ်။

| ကုမ္ပဏီ | Model များ |
|---|---|
| OpenAI | GPT models |
| Meta (Facebook) | Llama models |
| Amazon | Titan models |
| Google | Gemini / BERT models |
| Anthropic | Claude models |

### လိုင်စင် ပုံစံနှစ်မျိုး (License Types)

မော်ဒယ်လ်တွေကို နှစ်မျိုး ခွဲခြားနိုင်ပါတယ် -

- **Open-source (အခမဲ့):** မည်သူမဆို ယူသုံးနိုင်၊ ပြင်ဆင်နိုင်တာမျိုးပါ။ ဥပမာ - Meta ရဲ့ Llama သို့မဟုတ် Google ရဲ့ BERT။
- **Commercial License (စီးပွားဖြစ်):** အခကြေးငွေ ပေးရခြင်း သို့မဟုတ် သတ်မှတ်ချက်နဲ့ သုံးရခြင်း ဖြစ်ပါတယ်။ ဥပမာ - OpenAI နဲ့ Anthropic တို့ရဲ့ မော်ဒယ်လ်များ။

### အကျဉ်းချုပ် (Summary)

Foundation Model ဆိုတာ တက္ကသိုလ်က ဘွဲ့ရထားတဲ့ ကျောင်းသားတစ်ယောက်လိုပါပဲ။ အခြေခံဗဟုသုတ အစုံရှိပြီးသားဖြစ်လို့ သူ့ကိုမှတစ်ဆင့် ကျွန်တော်တို့ လိုချင်တဲ့ အလုပ်တွေ (စာရေးခိုင်းတာ၊ ကုဒ်ရေးခိုင်းတာ) ကို ခိုင်းစေနိုင်တာ ဖြစ်ပါတယ်။

## ၃။ LLM ဆိုတာဘာလဲ?

LLM ဆိုတာ Generative AI လောကမှာ လူသားတွေလိုပဲ စာသားတွေကို နားလည်ပြီး ပြန်လည်ရေးသားနိုင်အောင် ပြုလုပ်ထားတဲ့ Model တစ်မျိုးဖြစ်ပါတယ်။

- **Generate coherent human-like text:** LLM ရဲ့ အဓိကအလုပ်က လူရေးတာနဲ့ တူတဲ့၊ အဓိပ္ပာယ်ရှိပြီး ရှေ့နောက်ညီညွတ်တဲ့ စာသားတွေကို ဖန်တီးပေးဖို့ ဖြစ်ပါတယ်။
- **Trained on large corpus of text data:** "Large" လို့ ခေါ်ရတာဟာ သူ့ကို လေ့ကျင့်ပေးထားတဲ့ အချက်အလက်တွေက အရမ်းများလို့ ဖြစ်ပါတယ်။ Internet ပေါ်က website တွေ၊ စာအုပ်တွေ၊ ဆောင်းပါးတွေ အကုန်လုံးနီးပါးကို ဖတ်ခိုင်းပြီး လေ့ကျင့်ထားတာပါ။
- **Billions of parameters:** ဒါက နည်းပညာစကားရပ်ပါ။ Parameter ဆိုတာ model တစ်ခုရဲ့ "သင်ယူနိုင်စွမ်း" ကို တိုင်းတာတာဖြစ်ပြီး LLM တွေမှာ ဘီလီယံနဲ့ချီတဲ့ parameter တွေ ပါဝင်ပါတယ်။ (အရေအတွက် များလေလေ၊ ပိုပြီး တော်လေလေပါပဲ)။

### LLM က ဘာတွေလုပ်ပေးနိုင်သလဲ? (Language Tasks)

ဘာသာစကားနဲ့ ပတ်သက်တဲ့ အလုပ်မှန်သမျှကို LLM က ကျွမ်းကျင်စွာ လုပ်နိုင်ပါတယ် -

- **Translation (ဘာသာပြန်ခြင်း):** တစ်ဘာသာကနေ တစ်ဘာသာကို သဘာဝကျကျ ပြန်ပေးနိုင်ခြင်း။
- **Summarization (အကျဉ်းချုပ်ခြင်း):** စာမျက်နှာအများကြီးပါတဲ့ စာတမ်းတွေကို အဓိကအချက်တွေပဲ ကျန်အောင် အကျဉ်းချုပ်ပေးခြင်း။
- **Question answering (မေးခွန်းဖြေခြင်း):** ကျွန်တော်တို့ မေးသမျှကို အချက်အလက်ကျကျ ဖြေပေးခြင်း။
- **Content creation (အကြောင်းအရာအသစ် ဖန်တီးခြင်း):** အီးမေးလ်ရေးတာ၊ post တင်တာ၊ ပုံပြင်ရေးတာ စတာတွေကို လုပ်ဆောင်ပေးခြင်း။

### ထင်ရှားတဲ့ ဥပမာ

- **GPT-4:** ဒါဟာ OpenAI က ထုတ်လုပ်ထားတဲ့ LLM တစ်ခုဖြစ်ပြီး ChatGPT ရဲ့ နောက်ကွယ်က အဓိက နည်းပညာဖြစ်ပါတယ်။

## ၄။ Generative Language Models အလုပ်လုပ်ပုံ

**၁။ Prompt ပေးခြင်း (Giving a Prompt)**

ကျွန်တော်တို့က LLM တွေကို စကားပြောတဲ့အခါ ဒါမှမဟုတ် ခိုင်းစေတဲ့အခါ ပေးလိုက်တဲ့ အမိန့်စာသားကို **Prompt** လို့ ခေါ်ပါတယ်။ ဥပမာ - "မြန်မာနိုင်ငံအကြောင်း စာတစ်ပိုဒ်ရေးပေးပါ" ဆိုတာမျိုးဟာ Prompt တစ်ခုဖြစ်ပါတယ်။

**၂။ အကြောင်းအရာအသစ်များ ဖန်တီးခြင်း (Leverage learned content)**

ကျွန်တော်တို့ Prompt ပေးလိုက်တဲ့အခါ မော်ဒယ်လ်ဟာ သူ အရင်က သင်ယူထားတဲ့ (Learned) အချက်အလက်အားလုံးကို အသုံးချပြီး ကျွန်တော်တို့ လိုချင်တဲ့ အဖြေကို အသစ် (New Content) အနေနဲ့ ပြန်လည်ထုတ်လုပ်ပေးပါတယ်။ သူက ရှိပြီးသားစာတွေကို ရှာပေးတာမဟုတ်ဘဲ အသစ်ရေးပေးတာ ဖြစ်ပါတယ်။

**၃။ ပုံသေမဟုတ်ခြင်း (Non-deterministic)**

ဒါက အရေးကြီးတဲ့ အချက်ပါ။ **Non-deterministic** ဆိုတာ "ခန့်မှန်းရခက်တာ" ဒါမှမဟုတ် "အမြဲတမ်း ပုံသေမထွက်တာ" ကို ဆိုလိုပါတယ်။

- လူနှစ်ယောက်က တူညီတဲ့ Prompt (ဥပမာ - "ကဗျာတစ်ပုဒ်ရေးပေးပါ") ကို ပေးရင်တောင် LLM က ထွက်လာတဲ့ အဖြေဟာ တစ်ယောက်နဲ့တစ်ယောက် မတူဘဲ ကွဲပြားနိုင်ပါတယ်။
- အဖြေက တစ်ခါနဲ့တစ်ခါ မတူတာဟာ LLM တွေရဲ့ သဘာဝဖြစ်ပါတယ်။

### မှတ်သားရန် အချက် (Key takeaway)

- **Prompt:** AI ကို ခိုင်းတဲ့ အမိန့်စာသား။
- **Non-deterministic:** တူညီတဲ့ မေးခွန်းကို မေးရင်တောင် အဖြေက အမြဲတမ်း ထပ်တူမကျဘဲ ပြောင်းလဲနိုင်ခြင်း။

ဒီ "Non-deterministic" ဖြစ်တဲ့ သဘာဝကြောင့်ပဲ AI က ပိုပြီး ဖန်တီးနိုင်စွမ်း (Creative) ရှိတယ်လို့ ယူဆကြတာပါ။

## ၅။ LLM ရဲ့ စကားလုံးရွေးချယ်ပုံ (Word Selection Process)

**၁။ Potential words alongside probabilities**

LLM တစ်ခုဟာ စာကြောင်းတစ်ကြောင်းကို တည်ဆောက်တဲ့အခါ နောက်မှာလာမယ့် စကားလုံးကို တစ်ခါတည်း အချောကြီး ရေးလိုက်တာမဟုတ်ပါဘူး။ သူက နောက်မှာ ဖြစ်နိုင်ခြေရှိတဲ့ စကားလုံးတွေရဲ့ စာရင်း (List of potential words) နဲ့ အဲ့ဒီစကားလုံး တစ်ခုချင်းစီရဲ့ ဖြစ်နိုင်ခြေ ရာခိုင်နှုန်း (Probabilities) ကို အရင်တွက်ချက်ပါတယ်။

ဥပမာ - **"The cat sat on the…"** ဆိုတဲ့ စာကြောင်းရှိတယ် ဆိုပါစို့။

AI က နောက်မှာလာမယ့် စကားလုံးကို အောက်ပါအတိုင်း တွက်ချက်နိုင်ပါတယ်-

| စကားလုံး | ဖြစ်နိုင်ခြေ |
|---|---|
| Mat | 80% |
| Floor | 10% |
| Chair | 5% |

**၂။ Algorithm selects a word**

အထက်က ရာခိုင်နှုန်းစာရင်းကို ရပြီဆိုရင် Algorithm တစ်ခုကနေ စကားလုံးတစ်လုံးကို ရွေးချယ်လိုက်ပါတယ်။ များသောအားဖြင့် ရာခိုင်နှုန်းအများဆုံး (Probability အမြင့်ဆုံး) စကားလုံးကို ရွေးတတ်ပေမယ့် တစ်ခါတလေမှာ ပိုပြီး Creative ဖြစ်အောင် ရာခိုင်နှုန်းနည်းနည်းရှိတာကိုလည်း ရွေးချယ်တတ်ပါတယ်။

### ဘာကြောင့် ဒါကို သိဖို့လိုတာလဲ?

ဒါဟာ ရှေ့မှာပြောခဲ့တဲ့ Non-deterministic (အဖြေအမြဲပုံသေမထွက်ခြင်း) ရဲ့ အကြောင်းရင်းပါပဲ။

Algorithm က ရွေးချယ်တဲ့အခါ ဖြစ်နိုင်ခြေအများဆုံး စကားလုံးကိုပဲ အမြဲမရွေးဘဲ (**Temperature** setting အပေါ်မူတည်ပြီး) အပြောင်းအလဲလုပ်တတ်တာကြောင့် ကျွန်တော်တို့ မေးခွန်းတစ်ခုတည်းကို မေးရင်တောင် အဖြေတွေ ကွဲပြားနေတာ ဖြစ်ပါတယ်။

### အနှစ်ချုပ် (Key Point)

LLM ဆိုတာ တကယ်တော့ **"နောက်ထပ်လာမယ့် စကားလုံးကို ခန့်မှန်းတဲ့စက်" (Next-word prediction engine)** လို့ ပြောလို့ရပါတယ်။ သူက စာလုံးတွေကို အဓိပ္ပာယ် နားလည်ရုံတင်မကဘဲ သင်္ချာနည်းအရ ဖြစ်နိုင်ခြေ (Probability) အပေါ်မှာ အခြေခံပြီး ရွေးချယ်သွားတာဖြစ်ပါတယ်။
